# MoodNotes — Daily Mood Journal

A simple and beautiful mood journal web app where users can save daily mood notes and track basic emotional patterns.

## Features

- Select daily mood with emoji buttons
- Add title and reflection
- View total journal entries
- See top mood and weekly entry count
- Save notes in browser using localStorage
- Delete individual notes
- Load sample data for demo
- Clean responsive UI

## Tech Stack

- HTML
- CSS
- JavaScript
- localStorage

## How to Run

Open `mood-notes.html` in any browser. No installation required.
