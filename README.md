# MoodNotes — Daily Mood Journal

MoodNotes is a simple and beautiful mood tracking web app where users can record daily moods, write reflections, and view their journal history.

## Description

MoodNotes is a clean and responsive daily mood journal web app built with HTML, CSS, and JavaScript. It allows users to select their mood, write short reflections, save journal entries, and view basic mood statistics. The app uses browser localStorage, so notes remain saved even after refreshing the page.

## Features

- Select mood using emoji buttons
- Add a title and daily reflection
- Save journal entries
- View total entries
- View top mood
- View weekly entry count
- Delete individual notes
- Load sample data for demo
- Data saved using browser localStorage
- Responsive and modern UI

## Tech Stack

- HTML
- CSS
- JavaScript
- localStorage

## How to Run

1. Download or clone this repository.
2. Open `mood-notes.html` in any browser.
3. Start adding your mood notes.
